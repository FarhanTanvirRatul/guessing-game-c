# Number Guessing Game

This is a simple number guessing game that I made using C.

The computer generates a random number between 1 and 100, and the player has to guess it. After every guess, the game gives a hint to help the player find the correct number.

## How It Works

- The computer chooses a random number between 1 and 100.
- The player enters a guess.
- If the guess is smaller, the game says to try a bigger number.
- If the guess is bigger, the game says to try a smaller number.
- When the player guesses correctly, the game shows how many attempts it took.

## What I Used

I made this project using basic C programming concepts such as:

- Variables
- if-else
- do-while loop
- scanf() and printf()
- Random number generation
- rand() and srand()
